# Integration Boundary

v0.1 implements the minimal production path: HTTP, vforge CLI, MCP client
delegation, Project asset registration, VisualScene binding, and PNG delivery.

Future work: frontend controls, improved contact sheet typography, full SVG path
rasterization, animation, video overlays, multi-track composition, and richer
semantic routing. No paid model, LLM, or image-generation provider is called by
this implementation.
